# 瞭望与问数系统 DataFinderAgentOS v0.3

基于 Tornado + SQLite 的政务数据采集与智能问数系统，覆盖权限治理、瞭望采集、数据仓库、模型引擎、数字员工、Crawl4AI 深度采集、OpenAI 兼容 SSE 问答、真实仓库统计分析、数据报告、关系图谱与双大屏可视化。

冻结的 API、数据库、SSE 事件与前端契约位于 `docs/`。团队协作另见 [开发指南](README_DEV.md)、[部署指南](README_DEPLOY.md) 与 [协作规范](CONTRIBUTING.md)。

## 技术栈

- Python 3.12 / Tornado 6.5.7 / ReportLab 5
- Crawl4AI 0.8.5 / Playwright Chromium
- MediaPipe 0.10.32 / OpenCV（多帧手势与人脸活体校验）
- SQLite3 + Repository 模式 / Tornado Template
- Layui 2.9.8 + Bootstrap 5.3.8 + 原生 CSS/JS/Canvas + 本地 ECharts / ECharts-GL

Layui、Bootstrap 与字体均落在 `app/static/dist/`，后台界面断网仍可加载本地 UI 资源；外部采集与模型对话本身需要目标服务可访问。

## 快速开始

```powershell
cd DataFinderAgentOS
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

`setup.ps1` 在项目目录创建 `venv`、安装锁定依赖并执行 `crawl4ai-setup`；`run.ps1` 只调用 `venv\Scripts\python.exe`。运行、测试与依赖安装均不得改用全局 Python。

浏览器访问：

- 用户端：<http://localhost:10010/>
- 管理端：<http://localhost:10010/admin/login>
- 演示超级管理员：`admin / 123456`

首次启动自动创建或迁移数据库，初始化系统角色、功能、菜单与演示超级管理员。数据库、Cookie Secret、模型密钥、虚拟环境与缓存均不进入源码 ZIP。

## 功能

### 用户侧问数工作台

- 注册与登录复用后台用户表、角色、状态与密码验证，停用用户无法登录
- 浅色企业/政务双栏工作台：左侧系统标识、默认模型切换与任务记录，右侧对话区与固定输入区
- 首次提问自动生成任务标题；会话与消息分别写入 `user_conversations`、`user_messages`
- 点击任务记录读取当前用户自己的历史消息，访问他人会话返回 404
- 输入 `/` 或 `@` 打开数字员工命令面板，支持键盘上下选择、Enter 确认与 Esc 关闭
- 数字员工优先使用专属模型，不可用时回退系统默认模型
- 内置 `@天气` 调用 wttr.in JSON 接口，收敛为当前温度、体感、湿度、风况与三日预报卡片
- 普通模型问答按 OpenAI `/chat/completions` + `stream=true` 请求，上游增量经 `/api/chat/stream` SSE 实时转发
- 每条回答显示响应秒数、真实 token 用量与模型/数字员工配置名称
- 自然语言识别仓库概览、来源分布、近七日趋势、深采进度、关系图谱与分析报告意图
- 统计只执行服务端固定只读 SQL，拒绝用户 SQL、提示词泄露与越权注入，不向前端暴露真实 SQL
- 报表按命中意图渲染 KPI、柱状图、折线图、环形图、关系图与明细表；普通闲聊不强制生成图表
- 未配置大模型时如实提示，仍允许使用无需模型的 API 数字员工
- 支持安全 Markdown、语音播报、音频播放器、停止生成、失败重试、会话删除与 PDF 导出
- 支持人脸档案录入/重录/删除、多帧活体人脸登录，并始终保留密码登录兜底
- 支持 MediaPipe 多帧手势快捷调度（胜利=天气、握拳=音乐、张开手掌=新闻），同手势 5 秒冷却

### 管理工作台与双大屏

- 工作台指标全部读取 SQLite：可用用户、今日会话、模型调用、今日采集、采集成功率、高风险预警与启用数字员工
- 最近任务、模型错误、系统服务状态与安全基线均来自真实记录或明确运行配置，不填充演示数字
- 数智大屏用本地 ECharts/ECharts-GL 展示三维地球来源点、来源分布、采集/模型/用户趋势、词频、热点与风险分布
- 舆情大屏由用户消息与仓库内容规则命中生成可追溯预警，支持处理中、已解决、误报与处理备注
- 两块大屏提供刷新、暂停刷新、全屏、图表数据表替代与 reduced-motion 降级
- 用户管理支持全局或按用户启停人脸登录
- 会话管理支持用户、日期、模型、数字员工与归档状态筛选，显示风险、命中词、耗时与 Token，支持归档、批量删除与 PDF 导出
- 系统设置执行类型/范围校验，注册、维护模式、默认模型、大屏刷新、采集超时/数量、上传大小与会话时长由运行时代码读取
- 管理端新增、编辑、删除与启停操作统一写入可筛选审计日志

### 权限管理

- 用户、角色、功能、菜单四个管理模块与动态侧边栏
- 用户、角色、功能列表采用「上方搜索/操作、中间列表、下方分页」布局，固定每页 20 条；用户支持批量启用、禁用与删除
- 普通用户与管理侧账号隔离
- 默认 `admin` 超级管理员保护：用户名、角色、状态不可改删，仅本人验证当前密码后可改自己的密码
- 内置系统管理员角色不可编辑、授权、停用或删除
- 功能支持一、二级结构；角色授权使用 Layui Tree，禁用功能不可继续授权或生成菜单
- 菜单支持排序与按角色预览，左侧导航由角色授权、功能状态与菜单状态共同生成
- 仅默认超级管理员可写权限配置四模块，其他管理角色只读；瞭源、采集、仓库、模型引擎为业务模块，持有对应 `role_feature` 即可使用
- Handler 服务端权限校验，不能通过隐藏菜单或伪造表单绕过

### 瞭源管理与瞭望采集

- 维护采集来源、请求地址、可用状态、请求头与可视化查询参数
- 按关键词和规则发起新闻采集，支持分页参数，结果响应式卡片列表每页 12 条
- 请求超时、无结果、目标站异常均返回明确状态，不将失败伪装成真实数据
- 请求头只保存业务所需字段，不复制个人 Cookie
- 采集任务统一为等待、运行、成功、部分成功、失败与已取消，支持真实进度、步骤日志、取消、失败重试与启动恢复
- 来源列表从任务聚合最近时间、成功/失败次数、成功率、耗时与最近错误，并提供手动执行入口

### 数据仓库

- 选择或全选采集结果批量入库；搜索、分页、详情查看与删除
- 重复数据幂等处理与深采标记；单条、批量与更新深采，可查看最新持久化正文
- 深采浮窗实时展示进度、状态、六步执行链、派发员工、日志与结果摘要
- 任务、日志及每次更新结果分别持久化，服务重启时未完成任务被安全标记为中断
- 深采只接收公开 HTTP/HTTPS 来源，进入 Crawl4AI 前执行内网与凭据地址校验
- 由系统 `@采集专员` 强制调用 Crawl4AI 无头 Chromium，提取标题、正文 Markdown、最终地址、状态码与链接统计；正文最多保存 200,000 字符
- 支持来源/日期/风险筛选、单条重采、批量删除/深采、CSV 导出与显式去重
- 稳定问数接口覆盖采集量、来源数量、七日趋势、失败率、高风险、关键词频率与平均耗时，返回结论、KPI、图表与表格

### 数字员工

- 新增、修改、删除、启停、搜索、分类与每页 8 条分页
- 模型 / Crawl4AI 型：默认或指定模型、必填系统提示词、任务模板、技能与网页采集配置
- HTTP API 型：GET/POST、公开接口地址、参数模板、超时与 JSON/数据卡片响应
- 统一使用 `@调度名`；后台预览明确显示真实返回或配置错误，不生成伪结果
- 内置系统「采集专员」不可删除或停用，负责数据仓库深采，且不暴露给普通用户
- 新增/编辑可多选上传 UTF-8 `.md` 资料，每名员工隔离到 `data/dgUser/<id>/`，调用时仅作为事实背景补充 Prompt
- 接口型员工运行时读取绑定接口的 URL、方法、参数、响应路径、超时与重试，并保留 SSRF、响应大小与敏感请求头限制
- 已启用 Skills 每次执行动态加载；提示词 Skill 改变最终提示词，数据库问数 Skill 调用真实 `QueryIntentService`，停用即失效
- TTS 使用数据库配置、长文本分段、音频缓存与调用日志；生图使用异步 OpenAI 兼容服务与数据库任务，未配置生视频时明确失败且不返回假地址

### 模型引擎

- 管理 OpenAI API 兼容模型配置，支持文本、图像、音频、视频、多模态与嵌入分类
- 模型新增、修改、删除、查询、分类筛选与默认模型设置
- 配置系统提示词、温度、top_p、上下文数与最大 token
- 通过独立服务层进行模型对话，Controller 不直接拼装外部 SDK 调用
- SSE 流式返回模型响应，并在模型卡片中展示 token 用量
- API Key 不回显、不写入前端脚本，也不进入提交包

## 安全基线

- Secure Cookie + HttpOnly + SameSite=Strict，所有 POST 表单启用 XSRF
- SQL 使用 `?` 参数占位，密码采用 PBKDF2-SHA256 100,000 轮加盐哈希
- 密码与人脸认证按连接来源和账号组合限制失败频率；未知账号仍执行等成本 PBKDF2，降低暴力破解与时序枚举风险
- 所有出站请求经统一网络防护 `app/core/net_guard`：公网地址校验 + DNS pinning，拒绝内网/回环/云元数据地址并消除 DNS 重绑定
- 模型输入把问题、历史和上传文档作为转义后的不可信数据分区，拒绝覆盖或泄露系统指令的提示注入
- 外部采集设置超时、响应大小限制与请求头白名单/CRLF 过滤
- 静态文件下载复用框架路径归一化校验，防目录穿越；用户可见文本统一转义，防存储型 XSS
- 请求编号、路径和审计字段统一限制为单行，敏感设置的变更前后值始终脱敏
- 模型与采集权限同时覆盖页面地址与数据接口

## 测试

```powershell
.\venv\Scripts\python.exe -m unittest discover -s test -v
```

自动测试使用临时 SQLite 数据库。外部采集、深度采集与模型/API 员工均通过模拟响应验证解析与异常处理，不把第三方站点实时可用性作为单元测试通过条件。回归覆盖权限与会话隔离、采集任务生命周期、来源指标、仓库操作、七类问数、接口与 Skills、TTS、多模态任务、统一舆情、设置生效、操作审计，以及 PDF、人脸、手势、语音与双大屏能力。验收另执行 Ruff、Python 编译、前端 JS 语法检查、空库/旧库迁移与 HTTP 冒烟。详细用例见 [docs/test_case.md](docs/test_case.md)。

## 配置

| 环境变量 | 默认值 | 说明 |
|---|---:|---|
| `DATAFINDER_PORT` | `10010` | HTTP 端口 |
| `DATAFINDER_DEBUG` | `0` | 设为 `1` 开启调试 |
| `DATAFINDER_DB_PATH` | `database/finderos.db` | 数据库路径 |
| `DATAFINDER_COOKIE_SECRET` | 自动生成 | 可从环境注入 Cookie Secret |
| `OPENAI_API_KEY` | 空 | 默认模型服务密钥，也可由模型配置引用运行环境 |
| `OPENAI_BASE_URL` | 空 | OpenAI API 兼容服务地址 |
| `DATAFINDER_LLM_MODEL` | 空 | 默认模型名称 |

不要把 `.env`、API Key、Cookie、真实抓包请求头或运行时密钥提交到源码包。

## 项目结构

```text
DataFinderAgentOS/
├── app.py                    # Tornado 入口，端口 10010
├── requirements.txt          # 固定 Tornado、LiteLLM 与 Crawl4AI 版本
├── requirements-dev.txt      # 项目 venv 内的测试依赖
├── setup.ps1 / run.ps1       # 项目 venv 安装与启动入口
├── config/                   # 端口、数据库、Cookie 与模型运行配置
├── database/                 # 运行时 SQLite 数据，仅提交 README
├── data/dgUser/              # 按员工编号隔离的运行时 Markdown 资料
├── docs/                     # API/数据库/SSE/前端契约与需求、约束、模板、测试用例
├── test/                     # Repository 与 HTTP 集成测试
├── tools/package.ps1         # 安全打包脚本
└── app/
    ├── controllers/          # 认证、管理、采集、仓库、深采、员工与模型请求
    ├── core/                 # 网络防护等跨模块公共能力
    ├── models/               # SQLite Repository
    ├── services/             # 外部采集、深采编排、数字员工与模型服务
    ├── templates/            # 用户侧模板（admin/ 为管理侧）
    └── static/               # 自定义资源与本地组件库
```

## 打包

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\package.ps1
```

脚本默认在项目上一级生成 `零界-0xBoundary-v0.3源码.zip`，ZIP 根目录固定为 `DataFinderAgentOS/`，自动排除 venv、数据库、密钥、用户上传、语音缓存、本地导出、日志、浏览器测试产物与旧 ZIP。
